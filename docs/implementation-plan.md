# Implementation plan

1. Auth/RBAC and PostgreSQL persistence.
2. Verification provider adapter, document upload, liveness/face match and manual review.
3. Creator discovery, invitations and configurable thresholds.
4. Gift request, QR and station scanning.
5. Courier-cost abstraction and tracking.
6. Email/in-app notifications; optional SMS/WhatsApp providers.
7. Admin operations, reports and suspicious-activity review.
8. Tests, CI, dependency scanning and observability.
